# Guía de Programas para el Bienestar

## Qué puedes hacer

- Información oficial de los programas sociales del Gobierno de México: pensiones, becas, Jóvenes Construyendo el Futuro, Sembrando Vida, etc.
- Requisitos, montos y canales de registro.

## Portal oficial

- https://programasparaelbienestar.gob.mx/

## Precauciones

- La inscripción/baja es un trámite oficial que el usuario completa manualmente.
- Montos y requisitos cambian con las reglas de operación vigentes.
- No se tramitan apoyos ni se piden datos personales.
