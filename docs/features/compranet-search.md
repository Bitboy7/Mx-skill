# Guía de CompraNet (licitaciones públicas de México)

## Qué puedes hacer

- Buscar licitaciones y contrataciones públicas del gobierno mexicano.
- Filtrar por palabra clave, estado y tipo de procedimiento.

## Superficies oficiales

- CompraNet: https://compranet.hacienda.gob.mx/
- Contrataciones Abiertas: https://contratacionesabiertas.hacienda.gob.mx/

## Precauciones

- No hay una API pública estable para todo el catálogo; los portales aplican anti-bot.
- La participación en licitaciones es un trámite oficial que el usuario completa manualmente.
- Solo consulta/guía.
